Accent themes: white text was unreadable on four of six

Each pair below is the real token colour, before and after. The number is the measured contrast of white text on that fill; AA body text needs 4.5:1. Green in dark mode sat at 1.99:1 — not a near miss. Any user who picked Green, Orange or Teal in Settings had primary buttons that failed by a wide margin.

Red-light and Purple-light already passed and were left alone. Values were solved for the minimum change that clears the threshold, not picked by eye — and --ring moved with --primary so focus rings still match their fill.

Borders: invisible, and split by role

Row separators measured 1.18:1 in light and 1.23:1 in dark — effectively not there. In a dense financial table, gridlines do real scanning work.

They were not simply darkened to 3:1. SC 1.4.11 governs UI component boundaries, not decorative rules, so the token was split: --input is a control boundary and now meets 3:1; --border is decorative and was raised enough to be visible without turning every table into a grid of heavy lines.

Arabic: mirroring was excellent, truncation was not

The same invoice list in both languages. The RTL implementation is genuinely strong — sidebar, column order, KPI strip, pagination arrows and iconography all mirror, and translation coverage is complete. It was better than most of what the audit expected to find.

The bidi bug. In an RTL cell holding LTR text, text-overflow: ellipsis trims the logical end — which lands at the visual beginning of the English string. Users lost the identifying prefix of every invoice title.

Fixed with dir="auto" on mixed-content cells, and now built into the column contract so a text column carries it automatically rather than relying on someone remembering.

One deliberate compromise. Rows are focusable and Enter/Space-activatable, but keep their implicit row role. Giving a <tr> a link or button role removes it from the table structure for assistive tech, costing the “row 3 of 10, column Customer” context that matters most in a dense grid.

The fully conformant pattern is a real link in each row's primary cell — about 21 components. Tracked, not quietly skipped.

A note on the evidence itself

Two capture runs were thrown away before this one. The first tripped the API rate limiter — 179 consecutive 429s knocked the session back to the login screen — and the second was caught by the onboarding redirect, because the seeded admin has hasOnboarded = false. Both produced 161 screenshots that looked plausible in a file listing and contained no application at all.

The harness now asserts each frame is really the app before banking it. Both failures became findings in their own right: the rate limit was too low for a data-dense ERP where one screen fires many parallel calls and an office shares a NAT address.
